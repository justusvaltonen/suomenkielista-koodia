# suomenkielista-koodia
Eipä ole tullu vielä vastaan. "Ole sinä se sankari joka paskoo kattoon". Koitan pitää muuttujat Suomen kielisenä. Tiedostonimet myös. Viinaa kossuu ja kaljaa, hölkyn kölkyn, ukkometso puukon kanssa ilmaveivillä Ville Peltosen ja Mika Halvarin kanssa. Kaikki mainitut henkilöt, asiat (substantiivit), tapahtumat, hetket ja ajatukset totaalisen kastikkeessa. Lisenssiä ei löydy suomeks. Ei ymmärrä täten käsitettä tekijänoikeus-käräjöinti tai vaikka esimerkiksi tekijänoikeus-uhkauskirje. Täytynnee vartoa tai saattaa seurata tekijänoikeus-kovakakku.
